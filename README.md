# 老熊AN插件

面向 Adobe Animate 的中文动画辅助插件，提供元件操作、动画效果、光影处理和补间曲线工具。

当前适用于 Windows 与 Adobe Animate 2023。

## 发布状态

本仓库用于发布插件安装包和使用说明，不发布插件业务源码。

目前尚未提供公开下载的安装包。安装包发布后，可在本仓库的 Releases 页面获取。

普通用户只需下载 EXE 安装包。

## 主要功能

- 基础操作：居中、翻转、轴点调整。
- 动画效果：抖动、弹跳、摇摆、残影、出窍、扩影、闪现、闪隐、瞬冲、石化和灰化。
- 光影处理：发光、打光。
- 补间曲线：常用缓动曲线及其不同方向。
- 使用方式：预览模式、一键模式、常用固定项和最近使用记录。

具体功能及参数以所使用版本的插件界面为准。

## 下载与安装

安装包发布后，请从本仓库 Releases 页面下载以 `.exe` 结尾的官方安装包。

1. 保存正在编辑的工程，并正常退出 Adobe Animate。
2. 双击 EXE 安装包，按提示完成安装。
3. 重新打开 Adobe Animate 2023。
4. 在“窗口 → 扩展 → 老熊AN插件”中打开面板。

更新时，请先保存工程并正常退出 Animate，再运行新版 EXE 安装包。

## 使用说明

1. 打开需要处理的 Animate 工程。
2. 按功能要求选择元件、图层或时间轴中的帧。
3. 在插件中选择对应功能并调整参数。
4. 预览模式下，点击“应用”后才会修改工程；一键模式下，点击功能按钮即执行。

插件中的效果示意用于辅助理解参数，不等同于当前工程的实际预览。请在 Animate 中检查生成结果及最终导出效果。

处理重要工程前，建议先保存并保留备份。
